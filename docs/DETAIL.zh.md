# 牛马经纪人 · 让天下没有难找的工作

> 简历是最不重要的一环，你的目标，你对市场水温的感知，并围绕市场需求反向调整当下的工作投入与更长期的职业规划，这三点都远比简历重要得多。
>
> 换句话说，为了搞清楚这三点，你持续研究、做新的尝试，并根据反馈修正判断，你的简历很难不出众。
>
> 因此，虽然这个产品的入口是简历，但这只是作为一个出发点，最初始的信源，而最最核心的功能实际上都是围绕着前面说的三件事进行构建的：

## 核心能力

### 1. 制定目标，帮你找到匹配的岗位
- 开启**官网定时巡检**后，定期更新已订阅的公开岗位。结合履历给出匹配理由和需要留意的差距。
- **深度解读与风险排雷**：对标真实履历拆解优势与规模落差，每条风险附带可直接带去面试的反问话术，并一键定位 JD 原文。
- **全流程跟进 + 系统日程**：新机会 → 已投递 → 面试中 → Offer 一屏推进，支持同步至 macOS 日历、提醒事项、Things 或导出 `.ics`。

### 2. 感知市场水温，洞察市场需求
- **能力雷达与技能象限**对照在招 JD、简历和工作成果，区分常见要求、高价值技能和资深岗位的加分项。后台洞察只用已定稿的简历。
- **在职卡位行动清单**：识别优势壁垒与高频缺口，拆解到本周 / 本月 / 本季度行动，支持一键补进简历、筛对应 JD 或发起 DSH 深入学习。
- **公司赛道与职级格局**：横向看清各家公司在细分赛道的放岗密度、资深岗占比、城市分布与上新节奏。

### 3. 反向影响投入，从日常沉淀高价值成果
- **工作成果提炼**读取你授权的 DSH 工作区中的本人发言，提炼带有原文引证的成果和复盘，先放进「待核对」。你可以核对内容和数字，再标记为「对外可用」。
- **多主干 + 岗位定向分支**：维护长期演进的通用主干与岗位定向版本；主干更新后可一键同步至落后分支，支持边聊边改、Tab 补全与实时 A4 PDF 导出。

> **最后，一切都是水到渠成，我的大牛和千里马们，祝你找到一份真正想做的工作！**

## 说明

- 插件的**状态数据**保存在本机 `~/.dsh/profiles/<profile>/career-broker/`。使用 AI 功能时，相关上下文会发给你在 DSH 中配置的模型服务商。深度任务和 Tab 补全可独立配置模型及推理强度。
- **可控与克制**：后台工作提炼、官网定时巡检与展开自动解读默认关闭，由你按需开启；请仅勾选个人或已脱敏工作区，切勿发送受 NDA 约束的保密信息。不模拟登录，也不代投递。
